# Pricing and Access

The core fed-edu GitHub Organization Onboarding guide is free.

| Offering | Access |
| --- | --- |
| GitHub organization onboarding | Free |
| Ko-fi support | Optional one-time support |
| Patreon | Optional monthly support; premium tiers may be paid |
| PayPal subscription | Optional subscription; plan ID configured in the payment script |
| Stripe buy button | Optional purchase; browser-side publishable key only |

No payment is required to read the onboarding documentation or request an organization invitation. Review the provider's own terms before paying. Never place secret payment credentials in this repository.
