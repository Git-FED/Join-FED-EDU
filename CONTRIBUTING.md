# Contributing to fed-edu Organization Onboarding

Thank you for helping improve this GitHub Organization Onboarding guide.

## What to contribute

- Correct inaccurate GitHub interface instructions.
- Improve accessibility, plain-language explanations, and navigation.
- Add or update image placeholders when GitHub changes its interface.
- Report broken links or confusing onboarding steps.

## Issue or pull request

Use the [onboarding-help issue form](.github/ISSUE_TEMPLATE/onboarding-help.md) for personal onboarding problems. Use a normal issue for documentation bugs or feature ideas. For a change, create a branch, edit the relevant file, test links and Markdown, then open a pull request.

## Pull request checklist

- Explain which onboarding step changed and why.
- Keep claims about GitHub behavior accurate and time-aware.
- Test Markdown links and HTML navigation.
- Do not commit secrets, tokens, private invitations, or unredacted screenshots.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Use clear imperative commit messages such as `docs: clarify team invitation steps`.
