# Official GitHub Organization Onboarding — fed-edu

Welcome to the **fed-edu GitHub Organization Onboarding** repository. This guide explains how to follow the [fed-edu GitHub organization](https://github.com/fed-edu), accept an organization invitation, accept a team invitation, and get help when something does not appear as expected.

This repository is an onboarding guide—not a software package. You do not need to install anything to follow the steps.

## Onboarding flow

1. **Follow the organization:** Visit [github.com/fed-edu](https://github.com/fed-edu) and select **Follow**.
2. **Wait for the invitation:** The organization administrator, [@git-fed](https://github.com/git-fed), will send an invitation to your GitHub account.
3. **Accept the organization invitation:** Use the **Join** button in the email, GitHub Notifications, or the organization page banner.
4. **Accept a team invitation:** If you were invited to a team, use the separate team invitation and select **Join**.
5. **Confirm access:** Open your GitHub profile and verify that fed-edu appears under your organizations.

## Finding the Join button

### In email
Open the invitation email from GitHub and select the prominent **Join** button. If the button is not visible, look for a link to view the invitation on GitHub, or use one of the methods below.

### In GitHub Notifications
Sign in to the correct GitHub account, select the bell-shaped **Notifications** icon, locate the organization invitation, and select **Accept** or **Join**.

### On the organization page
Visit [github.com/fed-edu](https://github.com/fed-edu) while signed in. A pending invitation may appear as a banner near the top of the page. Select **Join**.

> GitHub organization invitations commonly expire after seven days. If yours has expired, ask @git-fed to resend it.

## If you need help

Open the [onboarding-help issue form](https://github.com/fed-edu/fed-edu-org-onboarding/issues/new?template=onboarding-help.md). Do not post passwords, access tokens, secret keys, or private personal information in an issue.

For general routing, read [CONTACT.md](CONTACT.md). For technical support, use [SUPPORT.md](SUPPORT.md).
