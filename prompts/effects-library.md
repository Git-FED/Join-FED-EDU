# Effects Library

Use one main effect per page and remove any effect that competes with onboarding instructions.

- **Animated backgrounds:** video background, particle/wave field, animated gradient, god rays — use for a subtle hero atmosphere only.
- **Scroll-triggered:** parallax, scroll reveals, pinned sections — use to stage a long explanation without hiding content.
- **Interactive and mouse:** custom cursor, 3D card tilt, hover microinteractions — use for optional polish on desktop; never make hover required.
- **Typography and assets:** typewriter, Lottie, SVG line and morph — use for short labels or diagrams, not essential instructions.
- **Dynamic and theme layouts:** glassmorphism, claymorphism, marquee, dark/light mode, bento grid — use to organize content while preserving contrast.
- **UI and loading feedback:** skeleton loaders, page transitions, progress indicators, confetti — use only when a real wait or milestone exists.
- **Immersive audio and video:** ambient soundscape, audio feedback, video masking — default to off and never autoplay sound.
- **Advanced 3D and physics:** WebGL/Three.js, physics engines — use only when a static alternative exists and performance is measured.
