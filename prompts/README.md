# Prompt Library

This folder contains reusable prompts for maintaining the onboarding site and generating related static pages.

## Recommended chain

1. `ROLE.md` — set the daily-seed generator role and quality constraints.
2. `daily-seed.md` — choose a visual direction from axes A–H.
3. `landing-page-master.md` — generate the fed-edu landing page direction.
4. `effects-library.md` — choose restrained interaction patterns.
5. `performance-guide.md` — check performance and reduced-motion behavior.
6. `universal-github-to-website.md` — adapt the approach to another GitHub project.
7. `universal-github-to-website-quick.md` — use the short version when context is limited.

All prompts must preserve the core identity: this is **GitHub Organization Onboarding for fed-edu**.
