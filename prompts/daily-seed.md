# Daily Seed — Axes A–H

Choose one option from each axis. Use `index = (D × k) mod len` with prime `k` values `3, 5, 7, 11, 13, 17, 19, 23` for repeatable variation.

- **A — Visual language:** editorial / cyber-organic / quiet luxury / technical documentation / playful community
- **B — Layout archetype:** centered hero / split hero / bento grid / timeline / story scroll
- **C — Type system:** geometric sans / humanist sans / condensed display + neutral body / serif editorial / mono accents
- **D — Color system:** obsidian-cyan / midnight-violet / slate-lime / warm paper / high-contrast monochrome
- **E — Surface:** flat hairline / glass / paper grain / soft clay / blueprint grid
- **F — Navigation:** compact top bar / anchored side rail / progressive disclosure / sticky section tabs / breadcrumb trail
- **G — Motion:** static / subtle reveal / magnetic buttons / parallax / restrained particle field
- **H — Subject:** organization onboarding / invitation acceptance / team access / contributor welcome / support routing

## How to roll

Treat each axis as a list. For each axis, calculate its index with the daily integer `D`, prime `k`, and the list length. Choose the corresponding option, then remove any effect that competes with the onboarding instructions.
