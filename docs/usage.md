# How to Use This Onboarding Guide

Start with [00-onboarding-checklist.md](00-onboarding-checklist.md), then follow the numbered documents in order. The links in the root [README](../README.md) provide the same path for first-time visitors.

- **00:** Track the whole onboarding flow.
- **01:** Follow the fed-edu organization.
- **02:** Accept the organization invitation.
- **03:** Accept a team invitation and understand repository access.
- **04:** Resolve common email, account, and permission problems.

If you are contributing edits to this guide, read [CONTRIBUTING.md](../CONTRIBUTING.md) first.
