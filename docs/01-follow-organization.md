# Step 1 — Follow the fed-edu GitHub Organization

Following the organization is the first step in **fed-edu GitHub Organization Onboarding**. It helps the administrator identify people who want to join and provides a direct starting point for the invitation process.

## Instructions

1. Sign in to the GitHub account you want to use for fed-edu.
2. Open [https://github.com/fed-edu](https://github.com/fed-edu).
3. Confirm that the page header shows the `fed-edu` organization.
4. Select the **Follow** button near the top of the page.
5. Confirm that the button changes state or otherwise indicates that you are following the organization.
6. Wait for @git-fed to send the organization or team invitation.

![Follow button](images/follow-button.png)

> The Follow action does not automatically make you an organization member. You must still accept the invitation that the administrator sends.

## If Follow is missing

- Make sure you are signed in.
- Check that you are viewing the organization page, not a similarly named user or repository.
- Try opening the direct link again: [github.com/fed-edu](https://github.com/fed-edu).
- If the page still looks different, open an [onboarding-help issue](https://github.com/fed-edu/fed-edu-org-onboarding/issues/new?template=onboarding-help.md).
