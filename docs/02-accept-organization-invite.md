# Step 2 — Accept the Organization Invitation

After @git-fed invites your GitHub account, accept the invitation to complete the organization portion of onboarding. GitHub may show the invitation in email, Notifications, or on the organization page.

## Option A: Accept from email

1. Open the email address connected to your GitHub account.
2. Search for an email from GitHub about an invitation to join `fed-edu`.
3. Open the invitation email.
4. Find the prominent **Join** button in the message.
5. Select **Join**.
6. Sign in if GitHub asks you to authenticate.
7. Review the organization information and confirm the invitation.

![Join button in an invitation email](images/join-button-email.png)

## Option B: Accept from GitHub Notifications

1. Sign in to GitHub using the account that was invited.
2. Select the bell-shaped **Notifications** icon.
3. Look for a pending invitation to the `fed-edu` organization.
4. Select **Accept** or **Join**.
5. Follow any confirmation steps GitHub displays.

![Organization invitation in Notifications](images/organization-notification.png)

## Option C: Accept from the organization page

1. Visit [https://github.com/fed-edu](https://github.com/fed-edu).
2. Make sure you are signed in to the invited account.
3. Look near the top of the page for a pending-invitation banner.
4. Select **Join**.
5. Confirm that the organization now appears on your GitHub profile.

![Organization page invitation banner](images/organization-banner.png)

## Important timing note

GitHub invitations commonly expire after **seven days**. If the Join button says the invitation is no longer valid, ask @git-fed to send a new invitation.

## If the invitation is not visible

Use the [troubleshooting guide](04-troubleshooting.md). In particular, verify the email address connected to your GitHub account and make sure you are not signed in to a different GitHub account in another browser tab.
