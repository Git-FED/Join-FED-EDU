# GitHub Organization Onboarding Checklist

Use this checklist to join the **fed-edu GitHub organization**.

## Before you begin

- [ ] I have a GitHub account and can sign in to it.
- [ ] I know which email address is connected to that GitHub account.
- [ ] I am signed in to the GitHub account that should receive access.

## Onboarding steps

- [ ] Open [https://github.com/fed-edu](https://github.com/fed-edu).
- [ ] Select **Follow** near the top of the organization page.
- [ ] Watch the email address connected to GitHub for an invitation.
- [ ] Check spam, junk, promotions, and other filtered folders if needed.
- [ ] Open the GitHub invitation email.
- [ ] Select the **Join** button.
- [ ] If email is unavailable, open GitHub **Notifications** using the bell icon.
- [ ] Accept the organization invitation from Notifications or the organization page banner.
- [ ] If a team invitation arrives, open it and select **Join**.
- [ ] Open your GitHub profile and confirm that **fed-edu** appears under organizations.
- [ ] Open any repository you were told to access and confirm that your team permissions work.
