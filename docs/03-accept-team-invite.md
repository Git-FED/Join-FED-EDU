# Step 3 — Accept a Team Invitation

A **team invitation** is part of GitHub Organization Onboarding when an administrator wants to place you in a specific team. Teams can determine which repositories and permissions you can access.

## Organization invitation versus team invitation

- An **organization invitation** makes your account a member of `fed-edu`.
- A **team invitation** places you in a named team and may provide access to that team's repositories.
- If you are not already an organization member, accepting a team invitation may also complete the organization membership step.
- If you already belong to the organization, GitHub may add you to a team immediately without sending a separate organization invitation.

## Accept the team invitation

1. Open the email address connected to your GitHub account.
2. Find the team invitation email from GitHub.
3. Open the message and locate the **Join** button.
4. Select **Join**.
5. Sign in to GitHub if prompted.
6. Review the team and organization details.
7. Confirm the invitation.
8. Open the team or a repository you were told to access and verify that the expected permissions are available.

> Repository access is determined by the permissions assigned to the team. Joining the organization does not necessarily grant access to every repository.

## If you did not receive a team email

Check spam and filtered folders, then review GitHub Notifications. If the invitation is still missing, ask @git-fed to confirm the GitHub username and resend the invitation if necessary.
