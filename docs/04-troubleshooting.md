# Troubleshooting GitHub Organization Onboarding

Use this guide when joining `fed-edu` does not work as expected.

| Problem | Solution |
| --- | --- |
| No email received | Check spam, junk, promotions, and filtered folders. Confirm that the email address is verified on GitHub. |
| The Join button does not work | Sign in to GitHub and try Notifications using the bell icon, or use the banner on [the organization page](https://github.com/fed-edu). |
| Invitation expired | Ask [@git-fed](https://github.com/git-fed) to resend the invitation. Invitations commonly expire after seven days. |
| I am using the wrong account | Sign out of GitHub, sign back in to the intended account, and reopen the invitation. |
| I cannot find the organization | Open the direct link: [https://github.com/fed-edu](https://github.com/fed-edu). |
| Follow is missing | Confirm that you are signed in and viewing the organization page rather than a repository or user page. |
| Team access is missing | Confirm that you accepted the team invitation and ask the administrator which repositories the team can access. |
| GitHub says I am already a member | Open your profile, select Organizations, and look for `fed-edu`. You may only need a team invitation. |
| The page keeps redirecting | Clear a stale GitHub session or use a private browser window, then sign in to the correct account. |
| I see a permission error | Record the repository URL and error text, but do not share tokens or passwords. Contact @git-fed through the onboarding issue form. |

## What to include when requesting help

- Your GitHub username (never your password).
- The onboarding step where you stopped.
- The exact error text.
- Whether you checked email spam and GitHub Notifications.
- A screenshot with private information, tokens, and email addresses redacted.

Open the [onboarding-help issue form](https://github.com/fed-edu/fed-edu-org-onboarding/issues/new?template=onboarding-help.md).
